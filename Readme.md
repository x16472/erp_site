# 福祿貝爾營運中心

福祿貝爾營運中心是一套供幼稚園內部使用的園務資料平台。網站以實際 SQL Server 資料庫為來源，整合幼兒學籍、班級、分校、托育收費、交通接送、教職員及權限治理資訊，協助園務人員在同一個介面掌握日常營運狀況。

系統目前採唯讀模式，不提供新增、修改或刪除正式資料庫內容。

## 園務功能

- 園務總覽：呈現幼兒學籍、教學班級、教職員及接送服務的即時彙總。
- 班級概況：依 `班別名稱` 顯示班級代號、名稱及所屬園區。
- 資料查閱：以 `ALLtable` 教職員整合主檔為預設，可切換查閱全部 SQL Server 資料表。
- 托育收費：說明收費類別、項目、班別套用、繳費記錄及明細核對流程。
- 人事權限：依職務類別模擬最小權限矩陣，並呈現各園區的人力範圍。
- 園務研習：提供兒少資料保護、托育收費、權限及接送安全測驗。
- 團隊小憩：透過園務名詞配對遊戲協助教職員熟悉資料流程。

## 實際資料來源

後端使用專案既有 `.env` 內的連線資訊，透過 `pyodbc` 直接查詢 SQL Server。園務總覽目前會使用以下資料表：

- `學籍資料`：幼兒學籍彙總。
- `班別名稱`：班級代號、班級名稱與園區。
- `ALLtable`：教職員整合主檔與部門彙總。
- `搭交通車況`：接送服務彙總。
- `分校資料`：園區代號及彙總人力。
- `繳費類別`、`繳費項目`、`繳費班別`、`繳費記錄`、`繳費明細`：托育收費流程。

資料查閱頁會從 SQL Server 中繼資料取得全部資料表、欄位名稱、資料型別、Null 規則及資料筆數。每次最多回傳 50 筆，避免一次載入大量資料。

## 兒少資料與個資保護

- 前端不會直接連線 SQL Server。
- 所有查詢皆由後端建立，前端不能傳入任意 SQL。
- 資料表名稱必須先與 SQL Server 中繼資料完全比對。
- 身分證、居留證、地址、電話、銀行帳號、薪資、津貼、保險與稅務資料由後端遮罩。
- 幼兒、家長、緊急聯絡人及接送人員資料採個人或受限制分類。
- 薪資、銀行、健保、勞保、其他收入及異動金額資料表全部視為受限制資料。
- 練習案件只儲存在瀏覽器 LocalStorage，與正式園務資料庫隔離。
- `POST` 請求會回傳 `405`，網站沒有正式資料寫入功能。

## 安裝與啟動

建議使用 Visual Studio Code 開啟專案。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

啟動後開啟：

```text
http://127.0.0.1:8000
```

執行環境需安裝 Microsoft ODBC Driver 17 for SQL Server。系統會直接使用專案既有 `.env`，不會建立或修改該檔案。

## API

| 路徑 | 說明 |
| --- | --- |
| `/api/health` | SQL Server 連線狀態與資料表數量 |
| `/api/dashboard` | 幼兒、班級、教職員、接送及園務資料域彙總 |
| `/api/catalog` | 全部資料表、欄位數與資料筆數 |
| `/api/table?name=ALLtable&page=1` | 指定資料表的欄位結構與遮罩後分頁資料 |
| `/api/operations` | 托育收費資料生命週期 |
| `/api/departments` | 教職員部門彙總 |
| `/api/branches` | 園區代號與彙總人力 |
| `/api/roles` | 職務類別與建議權限矩陣 |
| `/api/questions` | 園務資料治理研習題庫 |

## 目前限制

- 尚未實作登入、單一登入及正式角色授權，敏感欄位因此一律在後端遮罩。
- 分校資料中的簡稱若未建檔，介面會以分校代號顯示。
- 網站不會修改 SQL Server；正式資料維護仍需由既有園務系統執行。
- 正式上線前應使用專用唯讀帳號、限制來源 IP、啟用 HTTPS 並保留查閱日誌。
