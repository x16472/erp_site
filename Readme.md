# ERP Site

這是一個以原生 HTML、CSS 與 JavaScript 製作的 ERP 前端介面原型。專案目前不需安裝套件或執行建置流程，可直接由瀏覽器開啟，適合用於版面展示、操作流程驗證與後續功能開發。

## 專案功能

- ERP 儀表板：顯示營運摘要、統計卡片與常用操作入口。
- 銷售管理：以表格呈現銷售單號、日期、金額與處理狀態。
- MIS 管理：提供使用者新增表單、角色選擇與帳號清單介面。
- 系統診斷頁：提供診斷選項、執行按鈕與模擬主控台輸出。
- 頁面導覽：儀表板、銷售管理與 MIS 管理頁可透過側邊欄互相切換。

## 專案結構

| 檔案 | 說明 |
| --- | --- |
| `home.html` | ERP 儀表板與主要功能入口 |
| `sales.html` | 銷售資料列表與工具列 |
| `mis.html` | MIS 使用者及權限管理介面 |
| `index.html` | 獨立的系統診斷與測試頁面 |
| `Readme.md` | 專案說明文件 |

目前各頁面的樣式與互動程式皆直接寫在對應的 HTML 檔案內，尚未拆分為共用的 CSS 或 JavaScript 檔案。

## 執行方式

### 直接開啟

使用瀏覽器開啟 `home.html`，即可從 ERP 儀表板開始瀏覽。若要查看系統診斷頁，請另行開啟 `index.html`。

### 使用本機伺服器

若電腦已安裝 Python，可在專案目錄執行：

```powershell
python -m http.server 8000
```

接著在瀏覽器開啟：

```bash
http://localhost:8000/home.html
```

系統診斷頁位於：

```bash
http://localhost:8000/index.html
```

停止伺服器時，可在終端機按下 `Ctrl+C`。

## 技術架構

- HTML5
- CSS3（內嵌樣式）
- 原生 JavaScript（內嵌程式）
- 無套件相依
- 無後端服務與資料庫
- 無建置、測試或部署腳本

## 開發說明

- 建議使用 Visual Studio Code 編輯專案。
- 文件與頁面應維持 UTF-8 編碼，以避免繁體中文字元顯示異常。
- 新增跨頁共用功能時，建議將重複的側邊欄、樣式及 JavaScript 逐步拆分為共用檔案。
- 目前畫面資料皆為寫在 HTML 內的示範資料，重新整理後不會保留操作結果。

## 已知限制

- 現有頁面部分繁體中文內容出現亂碼，且部分 HTML 標籤疑似受字元編碼問題影響。
- 多數按鈕目前僅顯示「尚未開發」類型的提示，尚未串接實際業務流程。
- 尚未實作登入、權限驗證、表單驗證及資料持久化。
- 尚未針對小尺寸行動裝置完成完整的響應式版面調整。
