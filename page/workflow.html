上方撰寫 main.go，下方操作 Go 互動指令。Ctrl / ⌘ + Enter 執行。

標準輸入（stdin）

執行前先填入資料，供 fmt.Scan、bufio.Scanner 或 os.Stdin 讀取；資料讀完即為 EOF。


                        

                            
                            
                            
                        

                        
支援 Go 互動指令、多行區塊、go run main.go、go fmt main.go、go version、help、clear、reset。

                        
使用 Yaegi 0.16.1 / WebAssembly 在瀏覽器內執行，內建標準函式庫；語法支援以 Yaegi 為準，未提供 go get 或完整 Go modules 工具鏈。
                        

                        
執行環境使用瀏覽器快取；程式碼與輸入留在此瀏覽器，不會傳送到外部編譯服務或安裝到網站後端。

                            標準輸入（input / stdin）
                            
執行前先填入資料，每行供一次 input() 讀取；資料讀完即為 EOF。每次執行都會從第一行開始。

                            
                            
                        

                        
                        

                        

                            
                            
                            
                        

                        
支援 Python 指令、多行區塊（空白行結束）、python main.py、pip install 套件名稱、clear、reset。

                        
程式在瀏覽器內執行，首次載入及安裝套件需要網路。套件須支援 Pyodide / WebAssembly；命令列為 Python 環境。

                        
pip install 只作用於此瀏覽器；Cookie 保留套件清單 30 天，套件檔案使用瀏覽器快取，重新開啟或重設時自動還原。
