# 銀盾共同體營運中心產品需求與實作範圍

更新日期：2026-10-26。本文件作為目前產品範圍與後續驗收基準；功能狀態依原始碼整理，不代表已完成正式環境或全裝置驗收。部署操作見 [Readme.md](../Readme.md)，資料規則見 [database.md](database.md)，頁面與 API 對照見 [frontend_pages_guide.md](frontend_pages_guide.md)。

## 產品定位

銀盾共同體營運中心整合公開企業官網、員工入口與 MIS 後台，支援出勤、營運日報、內部訓練、宣導影音及資料維護。品牌使用「銀盾共同體」與 Silver Shield，以「LIVE AND LET LIVE.」、誠信、專業、資源共享與共同體連結為內容方向。

官網以穩重企業視覺呈現四大產業據點：羅瓦德莊園、可可藝術沙龍、聯合工匠街、地下堅石礦場。現有品牌轉型已是產品背景，不再以全域關鍵字替換、舊資料庫更名或既往遷移指令作為當前需求。

## 使用角色與權限

| 角色 | 主要需求 | 目前驗證方式 |
| --- | --- | --- |
| 訪客 | 企業理念、據點、團隊與合作資訊 | 公開頁面及公開 API |
| 員工 | 進入系統、打卡、日報、訓練與影音 | 有效在職員工編號及員工工作階段 |
| MIS 管理員 | 員工／部門、出勤、日報與申論審核、官網、文件與題庫 | 員工身分加上 MIS 帳密，管理工作階段綁定目前員工 |

員工登入目前採員工編號驗證，不包含個人密碼、單一登入或多因素驗證。HTML 可以載入，敏感資料與異動權限由後端 API 檢查；工作面板尚未建立完整業務與驗證流程。

## 功能範圍

### 公開官網

- 展示企業理念、四大據點、團隊及合作資訊與地圖。
- 員工卡片僅提供公開介紹所需欄位，支援依部門篩選。
- 官網標題、副標題、公告與主題由 MIS 設定，提供預覽。
- 主題為銀盾藍、勳章紅、鋼鐵灰、專業白；據點與員工圖片使用專案靜態資源，地圖及影音另依賴外部服務。
- 彙總資料依資料庫查詢，不將員工、部門或文件筆數寫死為產品規格。

### 員工入口與工作台

- 入口提供「上班打卡並進入」與「不打卡進入系統」，兩者皆查驗在職員工。
- 工作台顯示員工資訊、公告、目前時間及當日最後打卡，提供補打卡、打卡下班與離開系統。
- 出勤以 SQL Server 時間及台灣工作日判定，當日先上班再交替；同時請求以交易避免重複動作。
- 不打卡進入與離開系統不新增出勤；完整紀錄由管理頁查詢。
- 快捷入口連至日報、題庫、官網、影音與工作面板。

### 營運日報

- 員工填寫日期、據點代碼、既定分類、數量與摘要，後端驗證格式及限制。
- 個人列表呈現狀態與歷程，允許對指定狀態補充回覆。
- 管理員依員工／事件篩選，要求補件、審核通過或退回，保留活動紀錄。
- 備註提供個資提示及部分格式攔截，不宣稱能辨識所有個資。
- 目前沒有商業合約、收費、帳務或薪資處理功能；營運流程摘要不等同這些系統。

### 教育訓練與題庫

- 員工頁面分為學科刷題與術科申論，不以 SOP 閱讀頁取代題庫。
- 學科提供科目、章節、來源與題型篩選，建立練習或模考、保存作答、續作、標記、交卷及檢討。
- 題型包含單選、多選、閱讀、填空、配對與申論；錯題本支援個人查閱及移出。
- 練習可以即時取得正解與解析；模考交卷前不回傳正解與解析。題組保存題目快照。
- 術科答案交由管理員人工審核與回饋，未提供自動申論評分。
- 管理端維護科目、章節、模考設定、題目草稿、發布／停用、批次設定與來源匯入控制。

### 宣導影音與縮圖

- 影音頁提供 YouTube、BiliBili、ニコニコ、Douyin、TikTok 五個分頁。
- 員工提交對應網址，後端驗證平台與格式、取得標題並產生嵌入或原站連結。
- 部分分享短網址與直播僅支援原站觀看；來源可能限制登入、地區或嵌入，不能以取得標題作為播放成功的保證。
- YouTube 與其他平台使用不同解析 API，均要求員工身分及 CSRF。
- YouTube 縮圖工具提供可用尺寸預覽、下載與另存連結；最近最多 8 筆查詢可重新載入或清除。
- 各平台播放網址與縮圖紀錄只保存在目前瀏覽器，不提供帳號間或裝置間同步。
- 目前沒有可見的知識搜尋或 SOP 閱讀入口；後端保留相關 API 不代表頁面已提供功能。

### 工作面板

目前建立環境一至環境四的分頁與佔位文字，並加入側欄及工作台入口。尚未定義環境的業務用途、資料模型、保存方式或完整權限流程，不視為已完成工作流程管理、SOP 閱讀或影音整合。

頁面仍有沿用的 SOP 標題、播放器狀態及影音腳本引用，需待具體需求確認後處理；本次文件整理不擴充功能。

### 員工管理與 MIS

- 員工管理提供組織架構、清單、明細、搜尋與在職篩選；員工編號建立後不提供更名。
- 維護姓名、性別、年齡、部門及職位等資料；照片接受 JPEG、PNG、WebP，單張上限 5 MiB。
- 部門提供新增、更名及停用；有在職員工時禁止停用。出勤依日期與員工篩選。
- MIS 集中官網設定、待審佇列、申論審核、來源同步、題庫維護及通用資料查閱。
- 通用查閱只開放 10 張白名單資料表，不是任意 SQL 或通用資料編輯器；系統初始化共包含 17 張業務資料表。

## 技術與資料邊界

前端使用原生 HTML、CSS、ES Modules，後端以 Go HTTP 服務（Python 業務透過 gRPC 執行）提供同來源頁面、靜態資源與 API，業務資料存於 SQL Server。員工 CSV 為批次同步來源，照片與來源文件存於檔案系統。

支援 Windows 本機啟動與 Windows Server Core LTSC 2022 容器。容器使用 IIS／ARR／URL Rewrite 代理至 Python；不將 Docker 建置成功或舊測試紀錄視為本次部署已驗收。

文件來源為 DOCX、DOC、XLSX、XLS、PDF；舊 DOC 與掃描 PDF 需另備轉檔或 OCR 工具。啟動預設同步 SOP，MIS 可同步文件及題庫草稿，來源解析失敗需回報。

## 安全、維運與驗收基準

- 員工與管理工作階段分開，受保護 API 驗證身分；資料異動依路由檢查 CSRF，輸入由後端驗證，資料值使用參數化 SQL。
- 資料查閱依白名單與欄位分類遮罩，現有規則有範圍限制，不能宣稱已完整遮罩所有個資。
- 工作階段存於程序記憶體，重啟後需重新登入；目前尚無集中工作階段服務。
- 網站目前為 HTTP，未完成 HTTPS、Secure Cookie 或資料庫連線加密；容器尚無檔案 volume，image 會包含部署用 `.env`。
- 響應式、鍵盤操作、表單回饋及外部影音需依實際目標裝置與環境驗收，不使用「完美響應式」或未執行的勾選清單作為品質保證。
- 現有單元測試為 `backend.test_training` 與 `backend.test_media`；影音採模擬回應，不能證明外部服務即時可用。
