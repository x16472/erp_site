# 產品需求文件：與官方前台優化專案
轉型為專業型商業組織—銀盾的企業入口網站

## 1. 專案概述
本專案旨在將現有入口網站（目前帶有幼稚園與教育機構色彩）進行全面重構與優化，轉型為[《銀盾》(Silver Shield)](https://home.gamer.com.tw/artwork.php?sn=2890369)的專屬企業入口網站與內部管理後台。整體風格需從「遊戲性、幼兒教育」轉變為「商業營運、家族企業、專業與誠信」的企業級風格，完全移除舊有幼兒教育相關的流程與文字，轉型為以「共同體銀盾」為核心的企業入口網站。前端需呈現專業、誠信、家族向心力的商業營運風格。

## 2. 全域設定與文案替換規則
請在`專案資料夾`範圍內，包括但不限於`前端UI`、`資料庫`內含資料中，執行以下關鍵字與概念替換：
- 品牌名稱：將所有「FROEBEL」、「菲爾銀盾幼兒園」等字眼替換為「銀盾 (Silver Shield)」或商標簡稱「S.S.」。
- 企業標語：從後台設定`可自訂的內容`的標題、副標題及介紹之外，將「我們相信幼兒透過操作、遊戲與真實生活建立理解。老師不是答案的提供者，而是觀察、提問與陪伴探索的人。」、「有節奏，也有自由探索的每一天」這類板塊，替換為基於「LIVE AND LET LIVE.」以及「以家族為核心、誠信與慷慨為本的商業共同體」的核心理念等議題。
    -   詳細理念如下：
    >   為舊式的盾型紋章，銀質的金屬色底上塗有藍與紅兩種彩色底，劃分十字的盾上繪有噴著火焰的西洋龍(銀底紅圖)以及單一片的黑色翅膀(藍底黑圖)，中間盾為純銀的箏形盾，盾面中心點向外隆起，畫出了十字。<br>
    >   盾紋的左右側裝飾有帶雪花的風雪圖形，上方裝飾著稍微向右觀看的銀色騎兵頭盔，頭盔上停著一隻銜著紅色石頭的黑鳥。<br>
    >   盾紋的下方有條寫著「LIVE AND LET LIVE.」的黃色布條。<br>
    >   以上所述的共同體的旗幟就如同註冊商標一般，但紋章本身是由個體而非家族所有，任何一名成員皆可在原本盾形紋章的基礎上做修改，加入個人特色或關聯性，作為個人的紋章使用。<br>

### 3. 前台介紹頁面優化需求
[index.html](/index.html)面向商業合作夥伴與訪客，需展現共同體的實力與多樣化產業。
前台頁面需展現銀盾共同體的專業度與商業價值，建議架構如下：
- 區塊 1：企業宗旨 (About Us)
  - 標題：「以家族為核心、誠信與慷慨為本的商業共同體」
  - 內文重點：強調重視成員間的聯繫與利益分配，鼓勵成員自創事業。
- 區塊 2：營運據點與產業 (Operations & Industries)
  - 將原有的「幼兒一日作息」區塊替換為「旗下產業與設施介紹」：
    - 羅瓦德莊園：共同體根據地、住宅與管理總部。
    - 可可藝術沙龍：金錢生產設施與高端甜品營業部。
    - 聯合工匠街：包含鍛造、裁縫與抄錄的生產製造中心。
    - 地下堅石礦場：原物料採集與重機具營運。
- 區塊 3：團隊介紹 (Meet Our Team)
  - 保留現有員工卡片式排版，但套用新的部門與職稱。
  - 描述需從「陪伴孩子」轉變為「專業的商業營運與後勤支援」，強調工作能力與專業特質。
- MEET OUR TEAM的「陪孩子探索，也陪家庭安心」改為「專業後勤團隊」強調作為客戶最強力的支柱。
- 組織架構調整（部門名稱重構）：
  - 教學部 -> 業務銷售部 及 生產製造部
  - 保健部 -> 醫療與福利部
  - 輔導部 -> 人事部
  - 職稱轉換範例：幼兒教師 -> 業務專員 / 音樂教師 -> 工匠接顧問 / 體能教師 -> 倉管專員 或 生產製造專員。
- 針對「商務合作」部分進行優化。


### 3.1 多樣化產業與據點介紹 (Business Sectors)
針對共同體旗下事業進行模組化展示，包含：
- **莊園管理與行政中心**：內部營運與綜合管理服務。
- **藝術沙龍與餐飲精品**：商業零售與高端顧客體驗。
- **聯合工匠與製造區**：精密鍛造、裁縫與客製化生產。
- **資源採礦與基礎設施**：地下探勘與自動化開發。


### 3.2 旗下產業與設施介紹
取代原有的作息區塊，改為模組化展示四大營運據點：
- 羅瓦德莊園：共同體根據地、住宅與管理總部。
- 可可藝術沙龍：對外營運商業設施與高端甜品營業部。
- 聯合工匠街：包含鍛造、裁縫與抄錄的生產製造中心。
- 地下堅石礦場：原物料採集與重機具營運。


### 4. 後台管理頁面 (MIS) 優化需求
後台目前已具備資料表查找與員工管理功能，需進行介面與業務邏輯的商業化調整：
- 選單與模組調整：
  - 「在職研習區」 -> 改為「內部營運手冊」。
  - 「教育文件」-> 改為「營運SOP文件」，`題庫維護`、`Youtube`、`員工出缺勤`及`後台管理`維持不變。
- 資料庫顯示優化：
  - 前端 UI 在渲染資料表時，請將`Frobel_`相關命名在顯示介面上替換為`Company_`這類相對直覺的寫法，（例如：將 `Frobel_Staff` 顯示為 `Company_Staff` 或「員工主檔」）。
  - 資料表與變數命名：在獲取資料時，需將舊有的`Frobel_`前綴替換為`Company_`，例如`Frobel_WebSettings`改為`Company_WebSettings`，需要改動的部芬包括但不限於前後端、前台後台，以及資料庫名稱。

### 4.1 員工入口與內部前端調整

- sales.html：分為「新增營運日報」與「商業合約與帳務生命週期」。

### 5 營運資料蒐集表單限制

### 檢核結果：
1. 品牌與文案：公開網站、員工入口、內部工作台及 MIS 已統一使用「銀盾共同體」、「Silver Shield」與企業營運用語；功能程式碼檢索未發現舊幼教品牌文字。
2. 首頁與圖像：首頁已加入企業宗旨、四大營運據點、營運規模、專業團隊及商務合作區塊，所有頁面圖像均由 `static` 資料夾載入。
3. 視覺與響應式：共用樣式改為銀盾藍、勳章紅與鋼鐵灰三種企業主題，並為桌機、平板與手機設定響應式版面；本次以程式結構與 HTTP 載入測試確認，仍建議上線前由人工使用實際目標裝置完成最終視覺覆核。
4. 資料庫實體遷移：SQL Server 資料庫已由 `Frobel_New` 改為 `Company_New`，10 張應用資料表及相關限制式已由 `Frobel_*` 改為 `Company_*`；`.env` 的資料庫名稱也已同步修改。另經 `sys.objects` 實查並補正 12 個預設限制式、10 個主鍵及 3 個唯一限制式，共 25 個 SQL Server 自動產生的舊名稱，重新查詢的舊限制式數量為 0。
5. API 與權限：營運SOP及工安檢核 API 已採企業命名，員工與管理員端點均保留工作階段、資料庫在職狀態、CSRF 與權限驗證；MIS 僅能查閱白名單內的 10 張應用資料表。
6. 員工與部門：`data/staff.csv` 已改為企業職務與商業能力描述，部門由原先 15 筆整併為營運部、製造部、財務部、資訊部、福利部及後勤部六個啟用部門，名稱均不超過 5 個字。
7. 隱私限制：營運日報前端與後端皆會攔截姓名、身分證或居留證、電話、地址及電子郵件等可辨識個人的內容。
8. 驗證結果：Python 模組編譯、主要靜態頁面、公開 API、員工登入、管理員登入、資料表目錄、四大據點、營運SOP與工安題庫均已完成測試；測試工作階段已登出，測試伺服器亦已停止。
